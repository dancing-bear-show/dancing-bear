# Templates

Reusable document templates for this project. Copy the relevant template, fill in the placeholders, delete sections that don't apply.

| Directory | Contents |
|-----------|----------|
| `docs/` | RFC, troubleshooting guide |
| `pr/` | PR review-response template (for replying to Copilot/AI review comments) |

All generated text should follow `.claude/WRITING_GUIDE.md`.

The GitHub PR template itself lives at `.github/PULL_REQUEST_TEMPLATE.md` (see `.llm/PR_TEMPLATE_GUIDE.md` for usage notes) — it is not duplicated here.
